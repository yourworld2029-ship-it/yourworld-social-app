---
name: Coach diploma evidence format
description: Preserve private Sports Verification review support for Coach diplomas with two image sides.
---

Coach diploma uploads use the existing single Sports Certificate evidence path. When two images are selected, combine them in order into a two-page PDF before upload; a single image or multi-page PDF remains unchanged.

**Why:** The verification database and admin review flow store one certificate path. Combining the sides preserves both pages while avoiding a schema change and keeping the Player upload flow intact.

**How to apply:** Keep Coach selection limited to one PDF or up to two JPG/PNG images, validate each input, and enforce the existing 10 MB document limit on the resulting upload.
