1. AUTO-THUMBNAIL GENERATOR (Upload Route):
   - In the video/reel upload component:
     - If the user provides a custom thumbnail, use that `thumbnail_url`.
     - If NO thumbnail is uploaded, automatically extract a canvas frame snapshot from the video at 1.5 seconds:
       ```ts
       const generateVideoThumbnail = (videoFile: File): Promise<Blob> => {
         return new Promise((resolve) => {
           const video = document.createElement('video');
           video.preload = 'metadata';
           video.src = URL.createObjectURL(videoFile);
           video.muted = true;
           video.playsInline = true;
           video.currentTime = 1.5;
           video.onseeked = () => {
             const canvas = document.createElement('canvas');
             canvas.width = video.videoWidth || 640;
             canvas.height = video.videoHeight || 360;
             const ctx = canvas.getContext('2d');
             ctx?.drawImage(video, 0, 0, canvas.width, canvas.height);
             canvas.toBlob((blob) => {
               resolve(blob || new Blob());
             }, 'image/jpeg', 0.85);
           };
         });
       };
       ```
     - Upload this generated thumbnail blob to storage and save its URL in `thumbnail_url` in the database record.
